# LIQUIDS — физика жидкостей

Чистый C# в `Assets/_Project/Scripts/Core/Liquids` (пространство имён `SpaceSim.Liquids`, без UnityEngine, СИ, `double`).
Тесты: `Tests/EditMode/Core/LiquidPhysicsTests.cs`, `LiquidSimulationTests.cs`, `LiquidChemistryTests.cs`.

## 1. Типы

| Тип | Назначение |
|---|---|
| `LiquidDefinition` | Данные одной жидкости (никакого кода на жидкость): плотность, вязкость, поверхностное натяжение, теплофизика, фазовые переходы, химия. Методы вычисляют свойства от T и p. |
| `LiquidRegistry` | Библиотека жидкостей, правил реакций и исключений смешиваемости. Проверяет данные при регистрации. |
| `LiquidLibrary` | Стартовый набор с реальными данными и `CreateDefaultRegistry()`. |
| `LiquidReaction`, `ReactionTerm` | Правило реакции как данные: реагенты/продукты в кг на моль пробега ξ, ΔH, кинетика, условия (T, pH). |
| `LiquidChemistry` | pH, ионное произведение воды, расстояние Хансена, правила смешения (плотность, Аррениус, Рефутас). |
| `LiquidEnvironment` | Гравитация (вектор в системе контейнера, +Y — верх), давление, температура и плотность газа; `FromPlanet(PlanetPhysicalProperties, высота)`. |
| `LiquidPhysics` | Формулы: гидростатика, сила Архимеда, Стокс и скорость оседания при любом Re, число Бонда, Жюрен, Лаплас, Пуазейль, течение через трубу. |
| `LiquidSimulationSettings` | Геометрия ячеек, численные параметры, стенки контейнера. |
| `LiquidSimulation` | Сеточная симуляция (вертикальный 2D-срез конечной толщины). |

## 2. Модели

**Плотность**: ρ(T, p) = ρ_ref / (1 + β·ΔT + β₂·ΔT²) · exp((p − p_ref)/K). Твёрдая фаза — `solidDensity` (лёд 917).

**Вязкость**: Андраде μ = A·exp(B/T) или Фогель–Фулчер–Таммани μ = A·exp(B/(T − C)) (вода, глицерин).
Смесь: Аррениус ln μ = Σ xᵢ ln μᵢ (мольные доли); по запросу Рефутас (массовые доли, ν > 0.2 сСт).
`flowResistanceFactor` ≥ 1 умножает вязкое сопротивление (неньютоновские эффекты).

**Поверхностное натяжение**: σ(T) = σ_ref + dσ/dT·ΔT, 0 выше T_c. Используется в `CapillaryRise`, `LaplacePressure`, `BondNumber`.

**Кипение**: давление насыщенного пара — Антуан log10(p/Па) = A − B/(C + T) или Клаузиус–Клапейрон от нормальной точки
кипения; T_кип(p) — обратная функция, ограничена T_c. Теплота парообразования по Ватсону L(T) = L_ref·((T_c − T)/(T_c − T_ref))^0.38.
Тройная точка — `triplePointPressure` (данные) или p_нас(T_пл). Ниже неё жидкости нет: она частично испаряется и замерзает
(доля пара L_f/(L_f + L_v)), лёд сублимирует при T_s(p) (К–К от тройной точки с L_s = L_v + L_f).
Вода: 373.15 K дома (1 атм), ≈ 251 K на Кварисе (100 Па — жидкость невозможна), ≈ 561 K на Гермеус Море (75 бар).
CO₂: жидкость только между 216.58 K / 5.185 бар и 304.13 K / 73.77 бар; на Золине (60 бар) кипит при ≈ 295 K.

**Химия**: pH из эквивалентов сильных кислот/оснований (`acidityEquivalents`, моль/м³) с точным учётом K_w(T)
(pK_w = 4470.99/T − 6.0875 + 0.01706·T). Смешиваемость: исключение из реестра → металлы только с металлами →
расстояние Хансена Ra = √(4ΔδD² + ΔδP² + ΔδH²) < 25 МПа^½. Коррозия — скорость утонения стали (м/с) с Аррениусом;
разложение выше `decompositionTemperature` (первый порядок, эндотермическое, самоограничивающееся). Токсичность,
горючесть, реакционная способность — NFPA 704.

## 3. Сеточная симуляция

Ячейка хранит для каждой жидкости массу жидкой и твёрдой фазы и одну температуру. Взаимно смешиваемые жидкости
образуют фазовую группу (полная связь: в одной фазе только попарно смешиваемые жидкости — со-растворитель не объединяет воду и нефть; самые совместимые пары по Хансену объединяются первыми; считается один раз). Подшаг:

1. **Свойства**: ρᵢ(T, p), объёмы, ρ и μ смеси, теплоёмкость, гидростатическое давление (вес столба над ячейкой).
2. **Течение** через каждую грань: Δp = p_i − p_j + ρ·(g·d). Локальное давление ½ρgh для частично заполненной ячейки и
   ½ρgΔy + K·(f − 1) для полной (искусственная сжимаемость, максимум `maxCompression`) — без глобального решателя.
   Расход: Δp = b·Q + a·Q², b = μL/(kA) (щель Пуазейля, k = w²/12), a = ρ/(2C_d²A²) (Бернулли).
   Ограничители: не больше содержимого донора, свободного места приёмника и половины выравнивающего объёма.
   Вниз уходит сначала самая плотная фаза, вверх — самая лёгкая. Переполнение открытого верха — `SpilledMass`.
3. **Расслоение**: если сверху фаза плотнее самой лёгкой фазы снизу — встречный обмен равными объёмами,
   движущее давление Δρ·g·Δy (та же формула расхода, половина площади на поток). Работает и для тепловой конвекции.
4. **Диффузия** смешиваемых жидкостей: D = вихревая (`eddyDiffusivity`) + Стокс–Эйнштейн k_B·T/(6πμr), θ ≤ ½.
5. **Сливы и пробоины**: `PipeFlowRate` от манометрического давления у дна ячейки.
6. **Тепло**: теплопроводность между ячейками (гармоническое среднее k), стенки (`wallHeatTransferCoefficient`),
   свободная поверхность — конвекция h·(ρ_газ/1.2)^(2/3) и излучение εσ(T⁴ − T_окр⁴). Перенос массы несёт энтальпию.
7. **Фазовые переходы** при локальном абсолютном давлении (с учётом глубины), энергия сохраняется относительно T перехода.
8. **Реакции** по таблице правил (мгновенные или Аррениус + закон действующих масс), тепло −ΔH·ξ.
9. **Коррозия** стенок; при нулевой толщине открывается отверстие `breachHoleDiameter`.

Шаг делится на подшаги по условию Куранта: u = √(2·g·H), Δt ≤ C·Δx/u (не более `maxSubsteps`, дальше спасают
ограничители). Все массивы создаются в конструкторе; `Step` не выделяет память, стоимость O(ячейки × жидкости).
Масса сохраняется до округления: `TotalAccountedMass()` = содержимое + испарённое + пролитое + слитое + разложившееся + газ реакций.

## 4. Как добавить жидкость или реакцию

```csharp
var registry = LiquidLibrary.CreateDefaultRegistry();
registry.Register(new LiquidDefinition { id = "liquid_oxygen", referenceTemperature = 90.19, referenceDensity = 1141, ... });
registry.SetMiscibility("liquid_oxygen", LiquidLibrary.Kerosene, false); // при необходимости
registry.RegisterReaction(new LiquidReaction
{
    id = "a_plus_b",
    reactants = new[] { new ReactionTerm("a", 1.0), new ReactionTerm("b", 1.0) },   // кг на моль ξ
    products  = new[] { new ReactionTerm("c", 2.0) },                                // Σ реагентов = Σ продуктов + газ
    enthalpy = -50000, preExponentialFactor = 1e3, activationEnergy = 5e4, minTemperature = 300
});
var sim = new LiquidSimulation(registry, 32, 32, new LiquidSimulationSettings(),
                               LiquidEnvironment.FromPlanet(preset.Physical), "a", "b", "c");
```

Код физики менять не нужно: `Validate()` проверяет данные (в т. ч. баланс масс реакции).

## 5. Ограничения

- 2D-срез; внутри ячейки фазы не разрешены по высоте (граница раздела точна до ячейки). Сжимаемость искусственная:
  нижние ячейки глубокого контейнера хранят до `maxCompression` (2 %) лишнего объёма.
- Течение квазистационарное (без инерции жидкости): нет волн и всплесков; Гаусс–Зейдель с чередованием направления.
- Твёрдая фаза неподвижна (лёд не всплывает). Кипение компонентов независимое (без закона Рауля), испарения ниже
  точки кипения нет, пар сразу уходит из контейнера; соль при выпаривании рассола не остаётся.
- Идеальное смешение (без сжатия объёма вода–этанол, без максимума вязкости). pH только для сильных электролитов.
- Плотность CO₂ вблизи критической точки завышена (квадратичная аппроксимация); теплота плавления не зависит от давления.
- Смешиваемость по Хансену — эвристика с порогом и явными исключениями.
