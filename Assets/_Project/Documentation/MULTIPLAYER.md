# Командная миссия (мультиплеер)

Главное меню → **КОМАНДНАЯ МИССИЯ**. От 2 до 4 игроков, одна ракета, четыре роли:

| Роль | Что делает |
|---|---|
| **Капитан** | Разбирает миссию, выбранную командой, и раздаёт остальным то, что им нужно: вес и задачи робота, характеристики ракеты, как робота заберут. Связывает три остальные роли. |
| **Инженер** | Строит ракету под миссию: дистанция, масса робота, запас на ошибку человека (до предупреждения системы). |
| **Пилот** | Планирует полёт на готовой ракете и управляет ей. |
| **Водитель робота** | Собирает робота по снимкам со спутника (батарея, накладки на ноги, защита от радиации и температуры) и управляет им. |

## Правила лобби

- Минимум 2 игрока, максимум 4.
- У каждой роли не больше одного владельца; один игрок может держать несколько ролей.
- Миссию можно начать, только когда **все 4 роли заняты**, у каждого игрока есть хотя бы одна роль и все нажали «Готов».
  Если игроков меньше четырёх, кто-то берёт недостающие роли сам, или хост жмёт «Раздать свободные роли»
  (свободные роли достаются тем, у кого их меньше всего).
- Смена ролей снимает «Готов» у этого игрока; смена миссии — у всех.
- Командная миссия идёт в отдельном профиле в памяти (всё открыто, ничего не сохраняется), карьера игроков не трогается.

Логика лобби — `Scripts/Core/Multiplayer/CrewLobbyState.cs` (без Unity, покрыта `Tests/EditMode/Core/CrewLobbyTests.cs`).

## Режим

Только **онлайн через Photon**: каждый за своим компьютером, вход по коду комнаты (`HZN-XXXX`). Без установленного PUN 2 командная миссия недоступна — лобби покажет подсказку об установке.

## Подключение Photon PUN 2

1. Asset Store → **PUN 2 – FREE** → Import. PUN сам добавит символ `PHOTON_UNITY_NETWORKING`, и тогда скомпилируется
   сборка `SpaceSim.Multiplayer.Photon` (`Scripts/Multiplayer.Photon/`). Без PUN игра собирается и онлайн-кнопка
   показывает подсказку.
2. Создайте приложение на dashboard.photonengine.com (тип **PUN**), вставьте App ID в мастер PUN или в
   `Window ▸ Photon Unity Networking ▸ Highlight Server Settings` → *App Id PUN*.
3. Регион: если в настройках не задан *Fixed Region*, игра подключается к `eu`
   (`PhotonCrewNetwork.DefaultRegion`), чтобы все игроки попадали в один регион и находили комнату по коду.

### Как устроена синхронизация

Комната Photon закрытая (`IsVisible = false`), её имя — код комнаты. Свойства комнаты:

- `crew` — роли и «Готов» (`CrewLobbyState.Encode`, например `r=1,-1,3,3;ok=3`). Меняется через check-and-swap,
  поэтому двое, схватившие одну роль одновременно, не получат её оба.
- `mission` — выбранная миссия (меняет только хост).
- `start` — хост ставит при старте; каждый клиент, увидев его, сам грузит сцену полёта.

Список игроков — это игроки комнаты (actor number = id, master client = хост).

## Чат с капитаном

Только онлайн (на одном экране экипаж говорит вслух). Правило: каждый пишет только капитану, капитан — каждому,
игроки друг другу не пишут.

- У капитана справа панель **ЧАТЫ ЭКИПАЖА**: по одной ветке на каждого игрока. Заголовок ветки — роли игрока
  («ИНЖЕНЕР, ПИЛОТ»), под ним юзернейм; справа счётчик непрочитанных. Если игрок вылетел из комнаты — «· вышел».
- У остальных — панель **СВЯЗЬ С КАПИТАНОМ** с одной веткой.
- Панель живёт всю миссию (ангар, полёт, поверхность), сворачивается кнопкой «—» в плашку со счётчиком.
- Enter — отправить, Esc — выйти из поля ввода (пока поле в фокусе, клавиши полёта и пауза не срабатывают).

Устройство: `Core/Multiplayer/CrewChat.cs` — ветки и правило (тесты `CrewChatTests`), `Runtime/Multiplayer/CrewChatPanel.cs` —
панель (IMGUI), `CrewSession.SendChat`. По сети строка уходит событием Photon `41` (`RaiseEvent`, reliable) **только
одному адресату** (`TargetActors`), поэтому чужие разговоры до компьютера даже не доходят; отправитель берётся из Photon, а не
из сообщения, и получатель ещё раз проверяет правило.

## Что дальше

Сейчас роли фиксируются при старте (`CrewSession`: `Has(CrewRole)`, строка экипажа в HUD полёта), но сам полёт
ещё не синхронизируется между компьютерами. Чат с капитаном уже есть (см. выше). Следующие шаги: ограничение ангара/робота/пульта по ролям
и синхронизация состояния ракеты и робота через Photon.
